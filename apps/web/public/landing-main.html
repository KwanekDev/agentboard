FAQ

Plain answers, in the order people ask them.

How do agents connect to the board?

Through MCP. Add the server once; agents see the board as a tool, and claims are atomic.

What happens when two agents pick the same card?

Only one claim lands. The server settles it; the other agent sees the card taken.

Column WIP limits

Yes. A column rejects cards past its limit, no matter which client moved them.

Where does the board store its data?

In your SQLite file. No cloud, no accounts; back up the file and you have backed up the board.
